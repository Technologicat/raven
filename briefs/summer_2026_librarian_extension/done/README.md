# Completed briefs

Briefs from this sprint whose work has landed. Moved here rather than deleted: the *why* behind a
decision outlives the change that implemented it, and a brief is usually the only place it is written
down at length.

Move a brief here when its work is done — all of it. A brief that is "done except for one section"
stays in the parent directory, because the remaining section is what someone will come looking for.

The numeric prefixes are kept as they were, so a reference to "brief 02" resolves whichever directory
it now lives in.
